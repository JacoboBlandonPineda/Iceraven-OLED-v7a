# Iceraven-OLED-v7a

[![Generic badge](https://img.shields.io/badge/arch-armeabi_v7a-blue.svg)](https://en.wikipedia.org/wiki/ARM_architecture)  

This project applies an AMOLED dark mode theme to the **armeabi-v7a** version of [Iceraven Browser](https://github.com/fork-maintainers/iceraven-browser), addressing the lack of native OLED-friendly dark mode support in Firefox and its Android forks. This project is forked from [Iceraven-OLED](https://github.com/GoodyOG/Iceraven-OLED), with the explicit aim of producing builds compatible with the armeabi-v7a architecture and extending compatibility to older devices with displays that can take advantage of a pure black theme.

### Features  
- Automatically builds/releases APKs when updates occur in fork-maintainers/iceraven-browser  
- OLED-optimized dark theme for reduced battery consumption  
- Enhanced visual comfort in low-light environments
